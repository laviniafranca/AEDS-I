# AEDS I — Estudos Dirigidos
Repositório de estudos dirigidos e exercícios em linguagem C realizados durante a graduação em Ciência da Computação na PUC Minas.

## Objetivo
Registrar atividades acadêmicas e praticar conceitos de programação, resolução de problemas, funções, vetores, matrizes, strings e arquivos.

## Organização
- [`ED00/`](./ED00/): Exercícios introdutórios com funções auxiliares, arranjos, matrizes e métodos numerados.\n- [`ED01/`](./ED01/): Exercícios de programação com métodos numerados, operações aritméticas e funções auxiliares.\n- [`ED02/`](./ED02/): Exercícios de programação com métodos numerados e resolução de problemas usando C.\n- [`ED03/`](./ED03/): Exercícios com condições, caracteres, comparações e testes lógicos.\n- [`ED04/`](./ED04/): Exercícios de manipulação de caracteres e strings, incluindo contagem e separação de símbolos.\n- [`ED05/`](./ED05/): Exercícios com procedimentos, funções, sequências numéricas e somatórios.\n- [`ED06/`](./ED06/): Exercícios com funções, sequências, Fibonacci, fatoriais e somatórios.\n- [`ED07/`](./ED07/): Exercícios de geração e processamento de dados em arquivos de texto.\n- [`ED08/`](./ED08/): Exercícios com arranjos, leitura e gravação de arquivos, buscas e filtragem de dados.\n- [`ED09/`](./ED09/): Exercícios com matrizes, operações matriciais, transposição, diagonais e leitura/gravação em arquivos.\n- [`ED10/`](./ED10/): Exercícios com arranjos e matrizes alocados dinamicamente, busca, comparação e operações.\n- [`L01/`](./L01/): Lista de exercícios de programação em C, incluindo cálculos, caracteres e contagem de símbolos.\n

## Tecnologias
- Linguagem C
- Compilador compatível com C, como GCC

## Como compilar
Entre na pasta do exercício desejado e compile o arquivo `.c` correspondente. Exemplo:

```bash
gcc ED01.c -o ED01
```

No Linux/macOS, execute com `./ED01`. No Windows, execute `ED01.exe` (ou o nome escolhido para o executável).

Alguns exercícios incluem `io.h`, um arquivo auxiliar necessário à compilação; mantenha-o na mesma pasta do arquivo `.c`. Os exercícios que leem ou gravam arquivos de texto também podem depender dos arquivos `.TXT`/`.txt` presentes na pasta.

## Observação
Este repositório reúne atividades de estudo. Leia o código e os comentários de cada exercício para compreender os requisitos específicos. Antes de publicar, confirme que o compartilhamento das soluções está de acordo com as orientações da disciplina.
