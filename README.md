# AEDS-I
Sobre
Este repositório reúne estudos dirigidos e exercícios desenvolvidos durante a disciplina de Algoritmos e Estruturas de Dados I (AED I), no curso de Ciência da Computação da PUC Minas.

Objetivo
Registrar os exercícios realizados durante a graduação, praticar lógica de programação e desenvolver conhecimentos na linguagem C.

Organização
ED00 a ED10 - Estudos dirigidos 00 ao 10.

Tecnologias
Linguagem C
Compilador C, como GCC

Observação
Os arquivos deste repositório correspondem a atividades acadêmicas desenvolvidas durante meu processo de aprendizagem.
