# ED01

Exercícios de programação com métodos numerados, operações aritméticas e funções auxiliares.

## Arquivos
Os arquivos-fonte em C desta pasta correspondem aos exercícios deste estudo dirigido/lista. Quando houver um arquivo `io.h`, ele contém funções auxiliares utilizadas pelo programa.

## Como compilar
Abra um terminal nesta pasta e compile o arquivo principal. Exemplo:

```bash
gcc ED01.c -o ED01
```

Se o arquivo principal tiver outro nome, substitua `ED01.c` pelo nome correto. Em exercícios que usam `io.h`, mantenha esse arquivo na mesma pasta durante a compilação.

## Como executar
- Linux/macOS: `./ED01`
- Windows: `ED01.exe`

A execução pode variar conforme o exercício e pode exigir dados digitados pelo usuário ou arquivos de texto existentes na pasta.
